# XPlaneTool
A tool for Xplane developed based on Qt.

# Requirements

- Qt 6.6.3
- XPlaneConnect: https://github.com/nasa/XPlaneConnect



# Get Started

1. 安装X-Plane 9, 10, 11 or 12.
2. XPlaneConnect仓库内下载最新版本的XPlaneConnect.zip.
3. 将XPlaneConnect.zip 的文件复制到(`[X-Plane Directory]/Resources/plugins/`).
4. 使用QTCreator打开该功能进行调试，或直接下载最新发布的软件直接使用。
